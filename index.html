📘 Справка по модулю

Пропускная способность — максимальное число автомобилей, проходящих через сечение дороги в единицу времени.

Формула

P = 3600 / t × K, где t — время прохождения, K — коэффициент условий (0.7–1.0).

Передача данных

В Модуль 2 передаётся интенсивность N (авто/ч), которая используется для расчёта коэффициента загрузки Z = N / P.

📘 Справка по модулю

Коэффициент загрузки Z показывает долю использования пропускной способности.

Формула

Z = N / P, где N — интенсивность (авто/ч), P — пропускная способность (авто/ч).

Передача данных

В Модуль 3 передаётся интенсивность N для расчёта интервала движения автобусов.
